The framework & scoring

Every pillar is assessed within each architecture layer, and every answer traces back to a point on the page.

Seven pillars, across seven layers

The question set is a three-level tree: an architecture-layer category contains every WAF pillar, and each pillar holds the questions reworded for that layer. A gap therefore shows up exactly where it lives — not as a single average.

The seven pillars

Governance Interoperability & Usability Operational Excellence Security, Compliance & Privacy Reliability Performance Efficiency Cost Optimization

The seven architecture layers

Ingestion Storage Processing Orchestration Analytics AI ML

Choose which layers are in scope when you create the assessment — the score only counts what you selected.

How it's measured

Scoring is deterministic and fully transparent. Each question's status decides both the points it earns and whether it counts as answered.

Each answer is worth points

Status Counts as answered Points
Answer later No — the default 0
Open Yes 1
In Progress Yes 2
Completed Yes 3
Ignore Yes — for out-of-scope questions 0

Two numbers on the Results tab

Score %

Points earned ÷ the maximum possible, where the maximum is every in-scope question at Completed (3 points). Unanswered questions count as 0, so the score reflects both coverage and quality.

Completion %

Questions with any status other than Answer later ÷ the total in scope — how much of the assessment you've worked through, regardless of the answers.

Worked example. One pillar in one layer holds 5 questions, so its maximum is 5 × 3 = 15 points. A full layer of 35 questions maxes at 105; all seven layers together, 735.

Points roll up at every level

Question → Pillarwithin a layer → Layer → Overall score

Results also regroups each pillar's questions by WAF principle and ranks them highest-scoring first, so your strengths and gaps are easy to read at a glance.
